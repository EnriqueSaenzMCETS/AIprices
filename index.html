Cada modelo puede declarar toolSystemTokens en el JSON o editarse en la tabla. Se multiplica por las solicitudes que declaran herramientas, no por el total de funciones ejecutadas. Un cero significa que no se ha añadido una provisión fija separada; no es una medición de costos internos. No sumar de nuevo si los tokens reales ya lo incluyen.

Editar tokens acumulados por conversación

Cada perfil acumula todas sus llamadas LLM. El output ya incluye razonamiento. Las llamadas se registran para trazabilidad, no vuelven a multiplicar los tokens. Cambiar de escenario restaura sus perfiles de referencia.

Supuestos: las conversaciones sin compra abandonan antes del pago. No se han medido tokens, precisión ni latencia reales. Se excluyen caché, WhatsApp, pagos, infraestructura e impuestos. El consumo real y los reintentos pueden cambiar el resultado.

Haiku usa el precio mostrado para solicitudes de hasta 100,000 tokens de entrada. Si una llamada lo supera, aplica su tarifa superior; este simulador no detecta ese umbral a partir de totales de conversación. Terra se identifica como GPT-6.1 Terra, el nombre verificado en el catálogo.

El catálogo se carga automáticamente por HTTP desde models.json. Si abres este archivo directamente, usa Cargar JSON para seleccionarlo. Los resultados se calculan localmente. El diseño utiliza Tailwind mediante CDN (requiere internet para cargarlo); no hay llamadas a APIs de IA. Las ediciones de la web son temporales; para un cambio permanente edita models.json y recarga el catálogo. Descarga el CSV para conservar la estimación.
